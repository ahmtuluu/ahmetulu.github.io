Series and Parallel Resistor / Capacitor / Inductor Calculator

Enter your values and see the total for both series and parallel connection. Handy for building a value you do not have from two parts.

How is it calculated?

Resistors and inductors add up the same way; for capacitors the rule is reversed.

Resistor / inductor, series: R = R1 + R2 + …Resistor / inductor, parallel: 1/R = 1/R1 + 1/R2 + …Capacitor, parallel: C = C1 + C2 + …Capacitor, series: 1/C = 1/C1 + 1/C2 + …Magnetic coupling between inductors is ignored.

Two equal resistors in parallel give half the value (2 × 10 kΩ → 5 kΩ). A parallel result is always smaller than the smallest part, which is a quick way to sanity-check it.
