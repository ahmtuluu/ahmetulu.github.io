Resistor Color Code Calculator (4, 5, 6 Band)

Decode 4, 5 and 6-band resistor colour codes: pick the colours and see the value and tolerance. It also works backwards: type a value, get the colours.

How is it calculated?

Bands are read from left to right. The tolerance band is usually set slightly apart, on the right.

4 bands: [digit][digit] × [multiplier] [tolerance]5 bands: [digit][digit][digit] × [multiplier] [tolerance]6 bands: 5 bands + [temperature coefficient]Example: yellow-violet-red-gold = 47 × 100 = 4.7 kΩ ±5%

The “find colours from value” field rounds your value to 2 significant digits (4 bands) or 3 (5–6 bands) and picks the multiplier.
