PCB Trace Width Calculator (IPC-2221)

Enter the current, copper weight and allowed temperature rise to see the minimum PCB trace width and the loss along the trace.

How is it calculated?

The calculation is based on the equation fitted to the current vs. temperature-rise curves in IPC-2221.

I = k · ΔT^0.44 · A^0.725A = (I / (k · ΔT^0.44))^(1/0.725) [mil²]W = A / (t · 1.378) [mil], W(mm) = W(mil) · 0.0254k = 0.048 external, 0.024 internal · t: copper weight (oz) · 1 oz = 1.378 mil = 35 µm

Enter the trace length to get its resistance too. Copper resistivity rises with temperature, so ambient + temperature rise is used:

R = ρ · L / (W · t)ρ = 1.72·10⁻⁸ Ω·m · (1 + 0.00393 · (T − 20 °C))

In practice

  • Inner layers shed heat less easily, so they need roughly twice the width for the same current.
  • IPC-2221 curves are conservative and valid up to 35 A. The newer IPC-2152 is used for more detailed analysis.
