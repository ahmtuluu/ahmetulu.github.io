Buck Converter Inductor and Capacitor Calculator

Enter input/output voltage and current to get the minimum inductor, output capacitor, duty cycle and peak current for your buck circuit.

How is it calculated?

The calculations follow the basic buck equations in Texas Instruments application note SLVA477 and assume continuous conduction mode (CCM).

D = Vout / (Vin · η)ΔIL = (0.2 … 0.4) · IoutL = Vout · (Vin − Vout) / (ΔIL · fs · Vin)Ipeak = Iout + ΔIL / 2Cout = ΔIL / (8 · fs · ΔVout)ΔVout(ESR) = ESR · ΔILη: efficiency · fs: switching frequency · ΔIL: inductor ripple current · ΔVout: allowed output ripple

The maximum input voltage is used for the inductor, because ripple current is largest there. The tool also suggests the next E12 inductor value up.

In practice

  • The inductor saturation current must be above the calculated peak current.
  • Output ripple is often set more by ESR than by capacitance; fill the ESR field and the tool checks it too.
  • If the datasheet recommends a specific inductor and capacitor, use those first; this calculation is a starting point.
