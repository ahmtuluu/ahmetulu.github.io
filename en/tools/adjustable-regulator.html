Adjustable Regulator Resistor Calculator (LM2596, LM317, MP1584…)

Pick the chip: calculate the output voltage from the resistors, or find the resistor and nearest standard value for the voltage you want.

How is it calculated?

Adjustable regulators sense the output through a resistor divider and hold the FB/ADJ pin at an internal reference (Vref). There are two wiring styles.

FB type: LM2596, XL4015, MP1584

Vout = Vref · (1 + Rtop / Rbot)Rtop = Rbot · (Vout / Vref − 1)Rtop: Vout → FB, Rbot: FB → GND. Vref: LM2596 = 1.23 V · XL4015 = 1.25 V · MP1584 = 0.8 V

ADJ type: LM317, AMS1117

Vout = Vref · (1 + R2 / R1) + Iadj · R2R2 = (Vout − Vref) / (Vref / R1 + Iadj)R1: OUT → ADJ, R2: ADJ → GND. Vref = 1.25 V, Iadj ≈ 50 µA

In target-voltage mode the nearest values in the E24 and E96 series are suggested together with the real output they give.

Datasheet notes

  • LM2596: 240 Ω – 1.5 kΩ is recommended for the FB → GND resistor. The tool warns outside this range.
  • MP1584: keep the bottom resistor below 40 kΩ.
  • Vref itself has about ±2–3% tolerance; if you need a precise voltage, measure the output and trim.
