555 Timer Calculator (Astable / Monostable)

Build an oscillator or one-shot with the 555: calculate frequency, duty cycle and pulse width from R1, R2 and C.

How is it calculated?

The formulas are the equations in the Texas Instruments NE555 datasheet. The capacitor charges and discharges between 1/3 and 2/3 of the supply; 0.693 is ln 2, which corresponds to that range.

Astable (oscillator)

tH = 0.693 · (R1 + R2) · CtL = 0.693 · R2 · Cf = 1.44 / ((R1 + 2·R2) · C)Duty cycle = (R1 + R2) / (R1 + 2·R2)

Monostable (one-shot)

t = 1.1 · R1 · C

In practice

  • With this wiring the duty cycle is always above 50%. Add a diode across R2 for lower duty cycles.
  • A very small R1 makes the discharge pin sink too much current; a few kΩ or more is fine.
  • Electrolytic capacitors have wide tolerance (±20%); use a film capacitor for accurate timing.

Frequently asked questions

What is the 555 astable frequency formula?

f = 1.44 / ((R1 + 2·R2) · C). Duty cycle = (R1 + R2) / (R1 + 2·R2), so in the standard circuit it is always above 50%.

How do you calculate the 555 monostable time?

t = 1.1 · R · C. With 100 kΩ and 10 µF, about 1.1 seconds.
