Raspberry Pi and the Data Infrastructure: Laying the Foundation

Ahmet Ulu · April 2026

My job in this project was to lay the foundation of the system. That sounds modest, but by "foundation" I really mean building everything from scratch.

The database: the data has to go somewhere

The first task was installing PostgreSQL on a Raspberry Pi. I designed the table structures that would neatly store the data coming from the charging stations — temperature, humidity, energy consumption, occupancy. There was no real hardware yet, but the system was ready for it.

The first data flow with Arduino

On the hardware side, I set up serial communication between an Arduino and the Raspberry Pi. Simulated sensor data came from the Arduino, and Python read it and wrote it to the database. I wanted to see the data flow working before the real sensors arrived — and it worked.

License plate recognition: every vehicle gets its own section

Then I moved on to the part that interested me most: license plate recognition with a camera. The camera connected to the Raspberry Pi recognized vehicle plates and recorded them in the system. For each plate, a separate section was automatically created in the database — entry time, sensor data and history were all kept under that vehicle's plate. This made the system ready for multiple users as well.

Session structure and a REST API

Every time a vehicle enters the system, a new session starts, and it closes when the vehicle leaves. Thanks to this structure, which vehicle arrived when, how much it charged and all sensor data during that time can be tracked under a single session.

Finally, I wrote a REST API with Flask. My teammate developed the mobile app; the data was delivered to the app through the API and showed up on the screen. It was the first time I had written something that someone else used — that felt different.

Conclusion

The most important thing I learned at this stage wasn't actually the technical details. I saw how critical it is to divide tasks within a team, to communicate on time, and to keep an eye on whether the whole thing works instead of saying "my part is done".
